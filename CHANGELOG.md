# Changelog

## [0.1.0] - 2026-11-09

- Added a deterministic sensor and UART simulator with a localhost telemetry dashboard.
- Added CRC-16 packet encoding, stream resynchronization, loss/error counters, and threshold events.
- Added CSV replay data and generator.
- Added optional PySerial input and an ESP32 I2C/SPI/interrupt/UART firmware example.
- Added automated tests and Windows setup/engineering documentation.
